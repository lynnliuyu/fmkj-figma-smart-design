# 新增一个客户（开通外网访问）操作清单

服务器只配一次（已完成，见 `server/README-服务器一次性配置.md`）。之后**每加一个客户**：

## 1. 起个名字（30 秒）

给客户起一个短英文名，就是他的网址：`dealershanghai` → `dealershanghai.fmkj.top`
（只能用字母、数字、连字符，全小写。）

## 2. 在客户设备上跑一条命令（3 分钟）

```bash
# 在设备上（root）。frpc 二进制的下载地址在装机包里已带，脚本会自动装。
bash /opt/fmkj/app/scripts/deploy/enable-public-access.sh \
  --host 客户名.fmkj.top \
  --server 150.158.3.164:17000 \
  --token "$(cat /opt/frps/.token)" \
  --check
```

> token 在**服务器**上：`ssh root@150.158.3.164 'cat /opt/frps/.token'`（40 位随机，当密码保管）。

**买了公网访问的客户，装机时直接带上**，装完就是通的：

```bash
bash install-appliance.sh --registry 10.0.0.235:5443/fmkj-v3 --version <版本> \
  --public-host 客户名.fmkj.top \
  --tunnel-server 150.158.3.164:17000 \
  --tunnel-token '<token>'
```

脚本会：装 frpc → 写配置（客户专属子域名 + 每客户限速 2MB/s）→ 设开机自启 → 校验配置 →
等连上服务器 → 打印网址。加 `--check` 会顺手跑一遍外网安全自检。

## 3. 验收（1 分钟）

```bash
# 在任意一台联网电脑上：
curl -I https://客户名.fmkj.top/login        # 期望 HTTP/2 200
# 或者用脚本跑 7 项安全检查：
node scripts/deploy/check-public-access.mjs --url https://客户名.fmkj.top
```

看到 `7/7 项通过` 就交付。把网址发给客户即可。

## 4. 交付给客户时说清楚三件事

1. 网址是 `https://客户名.fmkj.top`，用管理员账号登录（密码是他第一次打开设备时自己设的）。
2. 在外网用比在店里用慢一点（要经过你的服务器），看图多的时候会更明显。
3. 手机 4G/5G 也能打开；如果打不开，先确认设备是否通电联网。

## 5. 关掉 / 换名

```bash
bash enable-public-access.sh --disable                    # 关掉
bash enable-public-access.sh --host 新名字.fmkj.top ...   # 换名（重跑一遍即可）
```

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 网址打不开，服务器上 `journalctl -u frps` 看不到该客户 | 设备的隧道服务没起来：`systemctl status fmkj-tunnel`，看是不是 token 错或出不了网 |
| 打开显示 404 | 访问到了服务器，但设备没连上（frps 没有这个域名的路由）；同上 |
| 打开一直转圈、或图片很慢 | 设备上行带宽不够（设备在家里用宽带，上传通常只有 30–50Mbps 的 1/10） |
| 证书报错 | 第一次访问会自动签证书，等 10 秒再刷新；还不行看 `journalctl -u caddy` |
| 想确认哪个客户在线 | `ssh root@150.158.3.164 'journalctl -u frps -n 50 \| grep "http proxy listen"'` |
