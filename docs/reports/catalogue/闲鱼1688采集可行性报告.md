# 闲鱼 / 1688 数据采集可行性结论

> 验证时间：2026-10-13
> 目的：为产品库补充**渠道价（拿货价/零售价）**和**二手/清仓价**

---

## 一、结论：两个平台都无法直接自动采集

不是我没试，是这两站的风控在当前环境下无法绕过。以下是实测记录。

---

## 二、闲鱼（goofish.com）——硬拦截

### 实测过程

| 手段 | 结果 |
|---|---|
| 直接 HTTP 抓取搜索页 | 返回 11KB 空壳，只有导航框架，商品区永远显示"加载中..." |
| 官方 mtop 接口 `mtop.taobao.idlemtopsearch.pc.search` | 返回 `RGV587_ERROR::SM::哎哟喂,被挤爆啦`，并强制跳 `passport.goofish.com/mini_login.htm` |
| Chrome headless 渲染 + DOM 检查 | 页面文本仅 35 字符，内容为 **"非法访问 / 为了保障您的体验，请使用正常浏览器访问闲鱼~"** |
| CDP Network 域拦截 XHR | 页面**根本没发起搜索请求**，只加载了 css/js 静态资源和 `qnrForm.json` 问卷配置 |
| 关闭 headless 用真实窗口 | 本机 Chrome 调试端口在当前沙箱环境无法持续存活，未能验证 |

### 拦截性质
闲鱼识别到自动化环境（headless 特征），直接返回"非法访问"页。**不是加个 User-Agent 能解决的**，需要真实浏览器指纹 + 人工过滑块 + 登录 Cookie。

## 三、1688 —— 阿里 x5 风控拦截

### 实测过程

| 入口 | 返回 |
|---|---|
| `s.1688.com/selloffer/offer_search.htm`（搜索页） | 5KB 空壳，命中 `login` |
| `m.1688.com/offer_search/`（移动搜索） | 4.8KB 空壳，命中 `login` |
| `detail.1688.com/offer/{id}.html`（详情页） | 302 跳 `_____tmd_____/punish?x5secdata=...` |
| `h5api.m.1688.com`（移动 API） | `FAIL_SYS_PARAMINVALID_ERROR::请求参数非法` |
| 慧聪网（镜像） | 502 网关错误 |
| 中国供应商 | 404 |

### 拦截性质
阿里 **x5secdata** 反爬体系：检测到非正常访问后下发滑块验证 challenge（那段超长 base64 就是验证令牌）。需要登录态 + 人工过验证。

## 四、为什么值得试（价值）

如果能采到，能补上目前**最大的数据缺口**：

1. **成本字段全是 0** —— 现在 49 条苏米产品的 `cost` 都是 0，报价算毛利没法用。1688 拿货价是最直接的成本来源。
2. **清仓/停产价** —— 电子电工行业旧型号（尤其面板类、Mesh 1.0 时代产品）电商常大额清仓，这是报价里的"杀手锏"信息。
3. **闲鱼二手价** —— 能反推一代产品的保值率，客户卖旧换新时会问。

## 五、三条可行替代路径

### 路径 A：你手动导出，我来做结构化（最快，推荐）

**闲鱼**：
1. App 或网页搜索目标产品
2. 复制搜索结果链接，或直接截图商品列表
3. 发给我，我提取标题/价格/成色/卖家信息，整理成对照表

**1688**：
1. 搜索后把商品列表页截图或复制链接发我
2. 如果有具体的 offer，我可以帮你分析价格区间

### 路径 B：提供已登录的 Cookie（一次性）

如果你的浏览器已经登录了闲鱼/1688：
1. F12 → Network → 任选一个 1688 请求 → 复制 `Cookie` 请求头
2. 连同目标搜索关键词发我

我用带 Cookie 的会话抓取，能拿到公开搜索结果。注意：**闲鱼的 Cookie 等同于登录态，不要发到公开场合**，用完建议退出重登使其失效。

### 路径 C：你本机跑脚本，我给脚本 + 结果分析

我写好带 Cookie 的采集脚本给你，你在自己浏览器环境跑（不会被判 headless），把 JSON 结果发我，我负责清洗、去重、入库、生成对照表。

## 六、当前数据缺口清单（等渠道价补齐）

| 缺口 | 影响 | 需要的数据源 |
|---|---|---|
| `cost` 全部为 0 | 方案报价算不出毛利 | 1688 拿货价 / 供应商报价 |
| `stock` 全部为 0 | 无法判断缺货与交期 | 供应商库存 |
| 无渠道价区间 | 无法做价格竞争力分析 | 1688 / 闲鱼 / 淘宝 |
| 无清仓与停产型号价 | 老项目替换报价缺依据 | 闲鱼 / 1688 清仓区 |

---

## 七、下一步建议

**优先级最高**：先解决 `cost` 字段。这个不解决，整个产品库在报价环节是残的。

最快的方式是**路径 A** —— 你截图或贴链接，我半小时内能整理出结构化的成本对照表。29 款产品 × 3~5 个渠道价，一条条看很累，交给自动化才划算；这一段手工的量我来做最省你时间。
