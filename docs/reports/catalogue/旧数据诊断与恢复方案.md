## 四、恢复方案（按优先级）

### 方案 1：恢复远程库 —— 唯一能拿回完整数据的路 ⭐

主机 `10.0.0.176` 一旦恢复，**立刻执行**：

```bash
# 在能访问该主机的机器上
pg_dump -h 10.0.0.176 -p 15432 -U postgres -d fmkj --format=custom --file=fmkj-old-$(date +%Y%m%d).dump
```

⚠️ **别拖**。主机长期离线意味着硬盘/实例随时可能彻底损坏或被回收，越早备份越好。

如果只是网络问题（同内段 `10.0.0.x`），可以先查：
```bash
ping 10.0.0.176
# 本机在 10.0.0.185/24 网段，理论上同网段直连，不通说明主机宕机而非路由问题
```

### 方案 2：从旧 Excel 重新导入

你 Windows 桌面上应该有这两个源文件（脚本里硬编码过路径）：
- `products_clean.xlsx` → 对应 `XLSX-CLEAN-*` SKU（511 张 imported 图就是它产的）
- `scraped_product_20260626045145032.xlsx` → 对应 `SCRAPED-*` SKU（82 张 scraped 图）

找到这两个文件，`scripts/import-products-clean.mjs` 和 `import-scraped-products.mjs` 改掉路径就能重跑。**这是最实在的方案**——数据源还在，只是库没了。

### 方案 3：图片反查重建（兜底）

已写好 `scripts/rebuild-from-images.py`，能从 91 张有信息量的图片重建产品骨架：

```bash
python3 scripts/rebuild-from-images.py          # 预览
python3 scripts/rebuild-from-images.py --apply  # 写库
```

实测能解析出 91 条：领普28、其他24、小米12、Aqara9、锐捷9、平头熊4、易来2、华为1、金闪1、鹿客1。

**局限**：只能拿到 名字/品牌/分类/图片，`price`、`cost`、`stock` 全空，58 条分类会落到"其他"（文件名信息不足）。**这是骨架，不是完整数据。**

### 方案 4：找 Vercel/Neon 生产库

项目 `.env.local.example` 提到 `DATABASE_URL=postgresql://USER:PASSWORD@HOST.neon.tech/...`。如果你在 Vercel 上部署过，**Neon 生产库可能还有完整数据**：

```bash
# 登录 Vercel 看环境变量，或在 Vercel Dashboard → Neon → 拿连接串
vercel env ls
```

这个可能性不低——苏米数据入库前，库里那些 Aqara/领普/H3C 数据很可能就在 Neon 上。
