# 上传图纸与户型图产物（设计记录）

Status: 部分实施（本机上传与户型图产物已可用；对接外部 CAD 服务、带点位标记、自动布点/自动报价尚未实施）
Recorded: 2026-10-21

本文件是架构图「上传图纸与户型图产物」页的依据，也记录尚未确定的部分。**不要**把本页的规划项当成已可用功能。

## 已确定的流程

在「准备并确认底图」之后，进入上传图纸环节：

1. **上传平面图纸**（已有）——本机上传平面图 / PDF / 图片，裁剪、净底后导入项目，生成户型图。
   实现入口：`lib/point-map-floorplan-crop.ts`、`scripts/prepare-cad-floorplan.mjs`。
2. **对接外部 CAD 服务上传**（尚未接入）——由客户自己的 CAD 服务接收原始图纸。
   接口、鉴权、回调与失败语义**均未确定**；接入前不得在外宣或界面中写成已支持。
3. 上传后先判断图纸是否可用（格式、范围、清晰度是否满足裁剪），不可用则处理原图后重传。

## 两种产物

| 产物 | 现状 | 说明 |
| --- | --- | --- |
| 只生成户型图 | 已有 | 净底户型图导入项目，随后人工布点、选型与场景设计 |
| 户型图带点位标记 | 规划 | 在户型图上生成候选点位标记，供后续自动布点与报价使用 |

## 自动布点 / 自动报价（规划）

- 定位：把「带点位标记的户型图」转成候选点位与报价预览，减少人工重复劳动。
- 约束：**复用**已有点位保存与报价预览模块（`lib/point-map-service.ts`、`lib/point-map-quote-refresh.ts`、`lib/quote-save.ts`），
  不新增第二套采购计算或另一个导出来源；报价仍走既有「独立保存报价」与固定版本交付。
- 未确定：候选点位的置信度与人工确认边界、标记来源（自有算法或外部服务）、失败与部分成功如何处理。
- 验收前不得声称可自动布点或自动报价。

## 对其它流程的影响

- 无点位方案的报价分支不变；本页只描述「户型图」的产生方式。
- 交付侧仍按既有约定：写入数据库才算已保存，固定版本与实际导出分别验证（见 ADR 0005、0007）。
- 「对接外部 CAD 服务」与已有的本机 CAD 导出接口（`docs/cad-export-api.md`，共享令牌）是两件事，不要混为一谈。

## 待确定

- 外部 CAD 服务的接口形态：同步返回还是异步回调；单文件与多楼层如何组织。
- 鉴权归属：客户服务自持凭据还是由本系统代管。
- 带点位标记的坐标系与现有户型图裁剪结果如何对齐。
- 自动布点的结果是否需要人工逐点确认后才能进入报价。
