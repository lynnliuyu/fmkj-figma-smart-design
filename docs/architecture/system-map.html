01 / 现在的系统怎样工作

浏览器负责编辑和展示；API 与业务服务位于同一 Next.js 应用。业务写入 PostgreSQL，图片和文件按现有来源读取。CAD 作为独立本机工具，通过人工导入接入设计工作。

02 / 一套系统，两种交付方式

线上托管版由运营方维护；本地版预装到黑豹 X2 后交付。两边使用同一核心版本，分别保存业务资料。官方产品库是可选服务，客户也能自行维护或混合使用产品。

软件更新、产品同步、业务备份分别操作

部署管理端承担更新权限，业务容器不直接获得 Docker 管理能力。升级要验证备份、迁移兼容与健康状态。

本地客户资料留在自己的设备

官方同步保留用户价格和本地修改；产品库到期停止获取新资料，不删除已同步内容，也不锁本地业务写入。

现有主流程 · 含点位项目

03 / 点位、报价和交付怎样衔接

把“本机预览”“数据库已保存”“固定交付版本”“实际导出文件”分开。历史 V 版本保持原资料，不因后续产品更新或图片调整而被改写。
