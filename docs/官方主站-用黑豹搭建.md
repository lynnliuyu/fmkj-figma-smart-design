# 把一台黑豹做成「官方主站」（客户下载产品库的地方）

> 一页操作。分两段：**你做的**（物理刷机）和**我做的**（装软件 + 配穿透 + 配域名）。

## 一、你要做的：把它刷成和我们出货机器一样的系统

原来装的是 Home Assistant 也没关系——那套系统是锁死的，装不了我们的服务，**直接刷掉**。

**用你出货机器同一张 Armbian 镜像、同一套刷法**（同型号，最省事）。这台是 Panther X2（RK3566），
两种刷法都可以：

| 刷法 | 怎么做 | 需要什么 |
| --- | --- | --- |
| **卡刷**（推荐，最简单） | 镜像写进 microSD → 插卡开机 → 进系统后把它装进 eMMC → 关机拔卡 → 从 eMMC 开机 | 一张 ≥8G 的 microSD + 读卡器 |
| 线刷 | USB 线连电脑，用瑞芯微工具（RKDevTool）写 eMMC | USB 线 + Windows 电脑 |

手上没有镜像文件时，参考（第三方教程，仅作线索）：
[Panther X2 Armbian 项目说明](https://github.com/fanglc233/Panther-X2-rk3566-npu-vpu-armbian/blob/main/documents/README.cn.md)、
[黑豹X2 刷机流程](https://blog.csdn.net/xueyong0403/article/details/144947582)、
[卡刷/线刷 Armbian 教程](https://juejin.cn/post/7508961566462017555)。

刷完开机，它自己会拿一个局域网地址 —— **告诉我一声，我扫出来接着往下配**。

## 二、我做的：装软件 + 配成主站 + 配域名

1. 用装机包装我们的软件（一条命令，和出货机器一样）。
2. 给它加上"运营方"的两项配置：
   - `CATALOG_PUBLISH_TOKEN`：客户设备拿它来取资料（相当于订阅凭据）
   - `CATALOG_SIGNING_KEY`：给资料签名，设备据此确认"是官方发的"
3. 给它配穿透：对外地址 `catalog.fmkj.top`（走你腾讯云那台做 HTTPS）。
4. 配每天自动备份（产品库是你的资产）。

## 三、之后每次上新的流程

1. 我在主站上把新产品录进去（或者你按表格导入）。
2. 点「审核通过」——**只有审核通过的产品才会发给客户**。
3. 客户的设备点「同步官方资料」就会拿到（默认只补新品，不动客户改过的价格）。
4. 成本价**不会**发出去（2026-10-22 定的：主站的成本是进货价，不下发）。

## 四、要提前知道的

- **同步快慢看你家/办公室的宽带上行**：目录小（几百 KB），产品图多就慢。
- **主站关机/断网时客户同步不了**：客户设备本地照常用，恢复后能补上。
- **刷机会清空它原来的数据**（Home Assistant 的配置、自动化都会没）。
