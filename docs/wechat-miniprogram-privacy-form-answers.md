# 微信《用户隐私保护指引》填写答案（逐项复制）

> 直接在微信公众平台「用户隐私保护指引」表单里按下面内容填写。

## 1. 开发者读取你的剪切板，用途是

用于把 AI 顾问回复的内容复制到剪贴板，方便你粘贴到微信或其他应用。小程序只在点击「复制」时写入剪贴板，不会读取与功能无关的剪贴板内容。

## 2. 开发者收集你选中的文件，用途是

用于上传你从微信聊天中选中的户型图、CAD 图纸等文件，生成项目点位图或进行 AI 识图分析。

## 3. 开发者收集你选中的照片或视频信息，用途是

用于上传你从相册选择或拍摄的户型图、现场照片，生成项目点位图、方案与报价资料。

## 4. 第三方插件信息 / SDK 信息

本小程序未嵌入第三方统计或广告 SDK。为实现功能，服务端会调用以下第三方服务：

- **DeepSeek（杭州深度求索人工智能基础技术研究有限公司）**：用于 AI 顾问对话与户型图识图。你在 AI 顾问中发送的文字和上传的附件会由我们的服务器转发给 DeepSeek API 处理；我们不会向其提供你的姓名、手机号、邮箱、微信 openid 等身份信息。
- **微信登录（腾讯）**：使用微信一键登录时，微信会向小程序提供 openid / unionid，用于账号绑定和登录。
- **腾讯云（服务器与存储）**：用于业务数据存储、备份与安全审计。

## 5. 需要「增加信息类型」补充的项

如果表单没有自动列出下面这些，请点「增加信息类型」逐条添加：

| 信息类型                   | 用途                                   |
| -------------------------- | -------------------------------------- |
| 手机号                     | 用于报价单/合同联系人展示和业务联系    |
| 邮箱                       | 用于成员账号登录、通知与联系           |
| 姓名                       | 用于项目负责人、报价单/合同联系人展示  |
| 微信 openid / unionid      | 用于微信一键登录和账号绑定             |
| 项目、点位、报价、合同数据 | 用于实现点位图、报价、合同、归档等功能 |
| 设备与日志信息             | 用于安全审计、故障排查                 |

## 6. 未成年人保护

保留默认文案即可：若你是 14 周岁以下未成年人，需要和监护人共同阅读并在监护人明示同意后使用；开发者将按法律法规和本指引处理经监护人同意的未成年人信息。

## 7. 你的权益（联系方式）

把默认文案里的「请选择 / 增加联系方式」补上：

> 你可以通过以下方式联系开发者，行使查阅、复制、更正、删除个人信息及注销账号的权利：
> 邮箱：`[请填写公司邮箱]`
> 电话：`[请填写联系电话]`
> 我们将在收到申请后 15 个工作日内完成核查和处理。

> 建议填公司对公邮箱或老板邮箱，不要填个人隐私邮箱；如果暂时没有，先用 `lynnliuyu@163.com` 也可以，但最好后续换成公司邮箱。

## 8. 开发者对信息的存储

选择「最短必要时间」，并可在说明里写：

> 你的信息在账号存续期间保存；账号注销或你申请删除后，我们将在 15 个工作日内删除或匿名化处理，法律法规另有规定的除外。

如果表单强制填固定天数，填 `0` 并选择「最短必要时间」即可；不要填一个很长的固定期限。

## 9. 信息使用规则 / 信息对外提供

保留默认文案即可，不需要额外修改。我们不会主动共享或转让你的信息给第三方，AI 对话内容只在实现 AI 功能所必需的范围内传输给 DeepSeek。
