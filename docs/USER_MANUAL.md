> **文档同步约定**：本手册与代码库 `src/lib/user-manual.ts` 及工作台 `/guide` 页面保持严格同步。后续任何针对核心流程、点位图工具、会员档位（`Go / Plus / Pro`）、国产 AI 大模型列表或积分计费规则的修改，均须同步更新 `src/lib/user-manual.ts` 与本文档。

## 一、核心主流程与基本用法（5 步闭环）

平台核心业务主链路简化为 **「项目信息 -> 点位图设计 -> 报价台 -> 合同 -> 归档导出」**，外围进阶能力均以插件形式在「插件市场」按需开启。

### 1. 项目信息与团队协作（`/projects`）

- **自动命名**：新建项目时录入客户姓名、电话、小区楼盘、房号、客户预算与主平台（米家 / Aqara Home / Apple Home / 华为鸿蒙智家 / KNX / Control4 等），项目名称留空时自动按「小区 + 房号」生成。
- **分享与协作**：支持开启只读分享链接发给业主在线查看，或生成团队协作邀请链接（单项目协作成员上限按项目负责人的会员等级计算：Go 版 2 人 / Plus 版 5 人 / Pro 版不限）。

### 2. 点位图设计工作台（`/projects/[id]/point-map`）

- **上传户型图与 DWG 转换**：支持上传 PNG / JPG / WebP 户型图（自动去除多余图框并适配 3:2 标准图纸）或通过「DWG 转户型图」插件直接上传 `.dwg` 文件。
- **比例标定与网格**：点击左上角工具栏「标定比例（`C`）」，在图上沿已知门洞或墙段拖一条线并输入实际米数，即可启用 25cm 网格与灯具真实尺寸落图。
- **多边形房间区域划分**：点击工具栏「画区域（`A`）」，依次点击房间拐角可绘制任意多边形房间轮廓，或直接拖拽绘制矩形区域；点位落入区域后自动按房间归类统计。
- **设备与灯光放置**：右侧面板分为「智能设备」与「灯光设计」，支持点击连续放置或拖拽放置，选中后可旋转角度（`R`）、切换灯具尺寸款式或修改设备类型。
- **智能生成点位（覆盖提示 + 一键撤销）**：
  - 点击顶部操作栏或画布左上角工具栏的 **「智能生成点位」** 按钮，系统会弹出确认对话框，明确提示 **「此操作会覆盖目标图纸上的当前点位（生成后可随时点击『撤销』或按 Ctrl/Cmd + Z 恢复）」**。
  - 若图纸已划分房间区域，按各房间类型自动排布全屋智能与灯光点位；若尚未划分房间区域，自动创建标准户型房间区域并生成点位。
  - 生成后可通过通知弹窗上的「撤销」、顶部操作栏「撤销」、画布工具栏「撤销」或快捷键 `Ctrl/Cmd + Z` 随时一键恢复原有点位。
- **导出规则**：导出的点位图 PNG 与方案平面图统一直接展示标准化 SVG 设备图标，而非纯数字编号。

### 3. 报价台与点位双向无缝联动（`/projects/[id]/quotes/[quoteId]`）

- **一键同步**：从点位图一键生成或同步到报价单，系统按点位类型汇总数量并匹配默认产品型号；在报价单中已手动替换过的型号与修改过的单价在同步时自动保留。
- **产品替换与优惠**：支持在 728 款产品库中搜索替换任意行型号、修改单价数量、设置整单优惠金额及安装调试/辅材附加费。
- **反向聚焦定位**：在报价单中点击任意房间或点位代号，可一键跳回点位图画布并自动放大聚焦到该点位或房间。

### 4. 施工合同管理（`/projects/[id]/contract`）

- 自动继承确认报价单的总金额与客户信息，支持设置三阶段分期付款比例（如 40% / 50% / 10%）、工期天数、质保月数与合同条款，并逐期登记收款状态。

### 5. 归档与多模板 PDF / 交付资料包导出（`/projects/[id]/archive`）

- **可视化方案模板选择器（`TemplatePicker`）**：
  - 在归档页与方案打印页顶部点击模板按钮，打开带**真实封面缩略图**的可视化选择器；
  - **业主方案与施工交底分离**：顶部独立切换「业主方案」与「施工交底（不含价格）」标签页；
  - 每张模板卡片清晰展示 **「适合什么客户」「什么时候用」「外观特点」「章节顺序与约计页数」** 以及前置会员等级标签（`Go / Plus / Pro`）；
  - 支持点击「预览样张」在弹窗内直接浏览整套横版方案，或开启「对比模板」勾选 2–3 套模板并排对比。
- **公开方案模板库（`/templates`）**：无需登录即可浏览全套模板封面、适用场景对比表、章节编排 6 条规范及每套模板的完整样张（`/templates/[slug]`）。
- **场景库双重保障**：后台「场景库」支持自定义场景与匹配规则；当新部署环境场景库为空时，自动启用内置 14 个标准生活场景（`src/lib/builtin-scenes.ts`），确保方案中的「生活场景」章节永不空白。
- **业主交付资料包（Plus / Pro 专属）**：支持在归档页勾选多份文档，一键合并为单份 PDF 或打包为 ZIP 下载。

## 三、国产 AI 大模型分级与积分计费规则

### 1. 管理员后台配置说明（客户不可自行配置）

- 全站 AI 渠道、密钥环境变量绑定、模型启停、计费倍率与所属会员档位（`Go / Plus / Pro`）**仅限超级管理员在 Payload 后台（`/admin/globals/ai-settings`）统一配置**，前台客户工作台不开放配置入口。

### 2. AI 对话与工具调用计费公式

每次对话按实际 Token 消耗与调用的系统工具累加计费（向上取整，单次最少 1 积分，接口报错不扣费）：

- **计算公式**：`单次扣除积分 = 向上取整( 模型计费倍率 * (输入Tokens/1000 * 0.1 + 输出Tokens/1000 * 0.5) + 工具调用费总和 )`
- **模型计费倍率**：Go 档标准高速模型默认 `1x`；Plus 档高阶视觉与长文本模型默认 `2x`；Pro 档满血深度推理模型默认 `3x`。
- **系统工具调用附加费（`TOOL_COSTS`）**：
  - `list_projects`（项目查询）：`+0.2` 积分
  - `get_project_details`（项目详情读取）：`+0.2` 积分
  - `get_document_links`（导出链接生成）：`+0.2` 积分
  - `search_products`（产品库检索）：`+0.3` 积分
  - `room_insights`（房间点位审查）：`+0.5` 积分
  - `create_project` / `update_project` / `set_project_defaults`：`+0.5` 积分
  - `add_floor_sheet`（上传户型图识图）/ `import_points_json`（导入点位 JSON）：`+1.0` 积分
  - `create_or_update_quote`（生成/修改报价单）/ `create_or_update_contract`（生成/修改合同）：`+1.0` 积分
  - `smart_select`（一键智能选型配单）/ `setup_rooms_and_points`（无图纸房间布点）：`+2.0` 积分

## 四、领域知识库导出、模板初始化与自动化测试脚本

无需阅读或修改业务代码，即可通过以下命令导出领域规则 JSON、更新知识库或运行规则回归测试：

| 命令                        | 用途说明                                                                                                                                                                                 |
| :-------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pnpm run knowledge:export` | 将设备字典、房间规则、智能选型规则、方案模板与编排规范、插件 AI 元数据、AI 工具 Schema 全部导出至 `./knowledge/*.json`（含单文件总表 `knowledge/domain-knowledge.json`），并自动运行测试 |
| `pnpm run knowledge:check`  | 仅运行 `./knowledge/tests/domain-cases.json` 中的声明式领域规则测试（可直接修改该 JSON 增删测试用例）                                                                                    |
| `pnpm run templates:seed`   | 将内置方案模板与 14 个内置场景（含图片）一键幂等补齐到数据库（后台 `/admin` 列表页顶部也可一键点击补齐）                                                                                 |
| `pnpm run templates:thumbs` | 调用无头 Chromium 自动渲染 `/templates/<slug>/slides` 并生成 `public/proposal-templates/<slug>.jpg` 静态缩略图                                                                           |

## 五、点位图画板快捷键速查

| 快捷键                          | 功能说明                                                     |
| :------------------------------ | :----------------------------------------------------------- |
| `V`                             | 切换到「选择 / 移动」工具                                    |
| `H` 或 按住 `空格` 拖拽         | 平移画布视野                                                 |
| `A`                             | 切换到「画区域」工具（点击拐角画多边形区域，拖拽画矩形区域） |
| `C`                             | 切换到「标定比例」工具                                       |
| `G`                             | 显示 / 隐藏 25cm 比例网格                                    |
| `Shift + R`                     | 显示 / 隐藏标尺                                              |
| `R`                             | 将选中点位顺时针旋转 90 度                                   |
| `Ctrl/Cmd + Z`                  | 撤销上一步操作（含一键撤销「智能生成点位」覆盖）             |
| `Ctrl/Cmd + Shift + Z`          | 重做上一步撤销的操作                                         |
| `Ctrl/Cmd + C` / `Ctrl/Cmd + V` | 复制选中对象 / 粘贴到鼠标位置并自动重编号                    |
| `Ctrl/Cmd + D`                  | 快速复制选中对象                                             |
| `Delete` / `Backspace`          | 删除选中点位或区域                                           |
| `Ctrl/Cmd + 0`                  | 将当前图纸 100% 居中铺满画布                                 |
| `Ctrl/Cmd + S`                  | 保存点位图                                                   |
