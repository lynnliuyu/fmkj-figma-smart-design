## 要做的事（按优先级）

### 1. 真实项目实景照（最高优先级）

现状：全站没有一张真实完工照，方案封面自己标着「氛围意向图 · 非项目实景」。

要求：
- 每个可公开案例 3–5 张：完工客厅、主卧、面板/中控特写、施工现场各一张；
- 横构图优先，长边 ≥ 2400px，不要加滤镜/水印；
- 放 `public/cases/<case-slug>/`，附 `manifest.json`：
  ```json
  { "title": "湖山赋 A区 12栋", "public": true, "rooms": ["living", "bedroom"], "shotAt": "2026-10" }
  ```
- `public: false` 的不得出现在公开页面或导出物里。

验收：`/cases` 页（或首页案例区）能按 `public:true` 渲染；素材侧可直接引用原图。

### 2. 展示版点位图（最高优先级）

现状：`gy-1f-light.png` 是施工图，标注引线、型号文字、图例全在，缩到视频尺寸就是一片灰线。

要求：
- 新增 `public/demo-plans/gy-{1,2,3}f-showcase.png`，与施工版同尺寸；
- 只保留：房间轮廓、点位圆点（沿用 `board/symbols` 配色）、房间名；
- 去掉：标注引线、设备型号文字、图例、图框；
- 背景透明或纯白（透明更好，视频里能直接压底色）。

验收：在 960px 宽下房间名可读、点位可数；无任何引线。

### 3. 单色设备图标（高优先级）

现状：`board/symbols/smart-home/*.png` 是 App 内的彩色符号（橙/绿/紫/粉），放在深色画面上颜色打架。

要求：
- 新增 `public/board/symbols/mono/`，同名单色版（白 + 金两套，或单色可染色）；
- 建议 SVG 或 512px PNG，透明底；
- 覆盖点：双开/三开/四开、射灯、筒灯、吸顶灯、灯带、窗帘、人体、网关、中控屏、音箱、AP、路由、门锁、摄像头。

验收：在 `#0B0D14` 底色上无描边发糊、无彩色残留。

### 4. 报价明细短名（顺手）

现象：列表里「易来智能LED嵌入式防眩筒灯射灯窄边框过道灯深杯无主灯 T3智能筒灯2.0…」被截成三行。
建议：产品库加 `shortName` 字段（如「易来 T2 开关」），列表优先用短名，全名放详情/导出附录。

### 5. 16:9 展示页（顺手）

现状：全站是竖长白页，没有可截成视频画面的固定版式。
建议：新增 `/showcase`，1920×1080 固定栅格：标题 + 大数字 + 点位图 + 报价摘要；供媒体、视频、投屏使用。

### 6. Logo mark（小）

左上角手写 mark 在 1440 宽下发糊，补矢量或 2x PNG 版本。
