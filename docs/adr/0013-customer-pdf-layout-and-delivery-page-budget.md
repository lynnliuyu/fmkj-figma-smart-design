# 0013 客户 PDF 紧凑排版与整包 10 页上限

Status: Accepted
Date: 2026-10-27

## Context

用户要求改善方案 PDF 与报价单 PDF 的客户可见设计，并按「客户交付」两份文件合计不超过 10 页。ADR 0011 曾保留每层图单独一页、整组明细避断，本次明确要求压缩留白和合并图页，因此替代这两条版式选择，不改变 ADR 0005—0007 的固定版本和报价规则。

## Decision

- 两份客户模版使用紧凑页头、信息网格、连续表格和完整楼层图，保留现代简约风格、品牌字段、全部行、场景、条款、原金额及未核验说明。正文至少 9pt。
- 楼层取消强制新页，允许同页多图；明细分组允许跨页，单条报价、标题与首行、楼层标题与图片保持完整。
- 客户交付任一下载先测量同一固定版本的两份完整文档，按正常、紧凑、更紧凑顺序选择合计≤10页的首档；仅收紧间距和图片高度，不删内容、不改价格、不裁图。实际 PDF 页数与所选测量结果一致。
- 仍超限或单条内容无法完整分页时明确停止下载，不静默截断。下载页脚显示单份页码及整包总页数，网页显示两份明细页数。
- 保留白底 JPEG PDF 下载与浏览器打印。原生打印使用同一密度预检，但其重复表头、用户缩放和打印机行为不同，最终页数由系统预览确认；联合硬上限针对客户交付的两个下载按钮。
- 方案预览与打印复用同一纯展示组件；不新增交付来源、采购计算、数据库字段或版本写入。报价编辑页独立出口仍先保存本页报价，不当作历史双份联合验收。首次提案四套风格仍独立，不属于此双份交付包。

## Consequences

模版单测和分页测试覆盖内容完整、合计预算、断页保护及失败行为；实际版式、真实 V1 页数、Preview/微信与纸张可读性另行验收。规则与本机步骤见 [PDF 导出与验收](../customer-pdf-export.md)。
