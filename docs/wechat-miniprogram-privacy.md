## 二、收集与使用的信息

本小程序用于智能家居设计、点位图、报价、合同与 AI 顾问，和网页版工作台共用同一套账号与数据。我们会收集以下信息：

| 信息类型                   | 收集场景                                             | 用途                                 |
| -------------------------- | ---------------------------------------------------- | ------------------------------------ |
| 微信 openid / unionid      | 使用微信一键登录时由微信提供                         | 识别微信账号、绑定成员账号、免密登录 |
| 姓名                       | 管理员在后台开通成员账号时填写；成员可在「我的」修改 | 项目负责人、报价单联系人展示         |
| 手机号                     | 成员在「我的」填写                                   | 报价单/合同联系人展示、业务联系      |
| 邮箱                       | 管理员开通账号时填写                                 | 登录账号、通知与联系                 |
| 登录密码                   | 成员登录时输入                                       | 账号认证（服务端只保存加密哈希）     |
| 上传的图片/户型图/CAD 图纸 | 项目点位图、AI 识图                                  | 生成点位图、报价与方案               |
| 项目、点位、报价、合同数据 | 使用对应功能时产生                                   | 业务数据存储与展示                   |
| 设备与日志信息             | 接口请求时由服务器记录                               | 安全审计、故障排查                   |

## 五、保存期限与删除

- 账号与业务数据在账号有效期内保存。
- 你可以在小程序「我的 → 修改资料」更正姓名、手机号；在「我的 → 微信绑定」解除微信绑定。
- 需要删除账号或全部数据时，请联系 `[你的邮箱或电话]`，我们会在验证身份后删除。
- 停用账号后，所有小程序令牌立即失效。

- 注销账号；
- 投诉与反馈：`[你的邮箱或电话]`。

## 代码侧对应关系

- `miniprogram/app.json`：`__usePrivacyCheck__: true`，全局注册 `privacy-popup`。
- `miniprogram/app.js`：`wx.onNeedPrivacyAuthorization` → 找到当前页 `<privacy-popup>`，用户点「同意」后 `resolve({ event: 'agree', buttonId: 'agree-btn' })`。
- `miniprogram/components/privacy-popup/`：隐私弹窗与《用户隐私保护指引》入口。
- `miniprogram/pages/mine/index`：「隐私保护指引」入口调用 `wx.openPrivacyContract()`。
- 涉及隐私接口：`wx.chooseMedia`、`wx.chooseMessageFile`；`wx.login` 用于微信登录。
