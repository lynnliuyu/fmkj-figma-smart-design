## 经验

- 沙箱里 `git commit` 偶发「先成功、重试报 nothing to commit」，会导致后面的 `push` 没执行；
  提交后要单独确认 `git status -sb` 与 `git log`，再单独 push。
- 提交信息里带换行时，`echo "$VAR" | node -e` 在 zsh 下会被 echo 解释 `\n` 导致 JSON 解析失败；
  改成 `curl -o 文件` 再 `require(文件)`。
